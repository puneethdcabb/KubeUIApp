## 📸 Key Highlights

- **🔒 Zero-Agent Architecture**: Connects directly over encrypted SSH (Port 22). No agents, daemons, or exposed Kubernetes ports required on your remote node.
- **🛡️ Enforced Sudo Admin Privileges**: All backend commands are automatically wrapped and executed with full `sudo` / root admin privileges behind the scenes, eliminating permissions errors when reading system files, PVC volumes, or container states.
- **⚡ Invisible Command Engine**: Runs all `oc`, `kubectl`, `podman`, and `docker` operations silently behind the scenes, transforming raw terminal outputs into an intuitive visual UI.
- **📁 PVC & Pod File Browsers**: Browse directories inside Persistent Volumes (PVCs) and Pod containers, view file contents, copy files directly to your Windows PC, and upload files into PVCs or pods.
- **💾 Windows File Exporting**: Export Pod YAML, Deployment YAML, PVC YAML, container logs, and remote files directly to Windows storage with one click.
- **🎨 Dynamic Themes**: Seamless real-time switching between **🌙 Dark Mode** (Catppuccin Mocha / Slate) and **☀️ Light Mode** (Clean GitHub Enterprise).
- **🔍 Behind-the-Scenes Transparency Drawer**: Live diagnostics of all executed SSH commands, duration (ms), exit codes, and stdout/stderr output with an interactive node command prompt.
- **🚀 Multi-Resource Management**: Pods, Deployments, Persistent Volume Claims (PVC), Containers, Docker Images, and Remote Linux Files.

## 🌟 Feature Tour

### 1. 🚀 Pods Management
- **Live Status Monitoring**: Color-coded badges for *Running*, *Pending*, *CrashLoopBackOff*, *ContainerCreating*, *Terminating*, and *Error*.
- **Namespace Switcher**: Filter pods by specific namespace or view *All Namespaces*.
- **Multi-Container Log Viewer**:
  - Container dropdown selection.
  - Line count selection (100, 300, 500, 1000, 3000).
  - `--previous` flag for viewing logs of crashed container instances.
  - Auto-refresh (3s polling) mode.
  - Instant text filter and search.
  - One-click copy and export to `.log` file.
- **Pod Actions**:
  - **📁 Browse Files in Pod**: Full container file system explorer. Inspect directories, view config and application files, download to Windows, and upload files into running containers.
  - **💾 Attached PVCs**: Instant one-click shortcut from any pod straight into its mounted PersistentVolumeClaim file explorer.
  - **🔌 One-Click Port Forwarding**: Establish local Windows port forwarding tunnels (`localhost:<port> -> container:<port>`) over encrypted SSH without manual CLI typing. Includes random port finder and "Open in Browser" button.
  - **⏹️ Stop Pod (Scale to 0)**: Smart shutdown shortcut. Automatically resolves the parent Deployment controller and scales replicas to 0 to cleanly stop the workload, preserving configuration and storage bindings.
  - **⚡ Operations**: Restart, Rollout Redeploy, Describe, View formatted YAML, Force Delete, and Exec command into pod container.

### 2. 📦 Deployments
- Desired, ready, up-to-date, and available replica tracking.
- **✏️ Interactive YAML Editor & Apply**: Edit live deployment manifests (image versions, environment variables, resource limits, replicas) with syntax highlighting, search/find, and one-click **"Apply & Redeploy"** or **"Apply Only"**. Automatically triggers rollout redeployment.
- **Interactive Scale Dialog**: Quick numeric counter with `+` and `-` steppers to scale replica count up or down.
- **Rollout Restart**: Trigger `rollout restart deployment/<name>`.
- Describe and YAML inspector with local Windows export.

### 3. 💾 Persistent Volume Claims (PVC) & Storage
- Real-time status (*Bound*, *Pending*, *Lost*), Volume name, Capacity, Access Modes, Storage Class, and Age.
- **📁 PVC File Browser**: Full directory navigation inside Persistent Volumes via mounting Pods (`oc exec`) or underlying node host storage paths (`/var/lib/microshift/data/...`, `/var/lib/containers/storage/volumes/...`).
- **💾 Copy Files to Windows PC**: Select any file in the PVC and save it locally to your Windows machine.
- **📤 Upload Files into PVC**: Copy files from your Windows PC directly into the Persistent Volume.
- **📄 YAML Export**: View and export formatted PVC YAML directly to Windows files.
- Guarded deletion with confirmation prompts.

### 4. 🔑 Secrets & Certificates / CRL Management
- **Full Secret Visibility**: Browse all secrets across any namespace or cluster-wide (`Opaque`, `kubernetes.io/tls`, `kubernetes.io/service-account-token`, etc.).
- **🔍 Describe Secret**: Detailed Kubernetes/OpenShift describe output showing annotations, labels, and base64 descriptions.
- **👁️ Secret Data & Certificate Inspector**:
  - Lists every key stored within the secret (`tls.crt`, `tls.key`, `ca.crt`, `ca.crl`, etc.).
  - **Raw Base64 View**: Inspect the exact base64 strings stored in the cluster.
  - **Decoded View**: Toggle with one click to readable UTF-8 text, PEM certificate blocks, or Certificate Revocation Lists.
  - **💾 Save Key to Windows**: Export any certificate, private key, or CRL file directly to local Windows storage.
- **📄 Export & Copy YAML**: One-click YAML view and direct export to local `.yaml` files.
- **🗑️ Delete Secret**: Safe deletion with confirmation dialogs.

### 5. 🌐 Ingress & OpenShift Routes
- **Unified Routing View**: Simultaneously discovers and aggregates Kubernetes `Ingress` and OpenShift `Route` resources (`route.openshift.io/v1`).
- **OS-Level Router Health Dashboard**:
  - Router Pod status in `openshift-ingress` or MicroShift embedded router.
  - OS-level verification of port **80** (HTTP) and **443** (HTTPS) listening status via `ss`/`netstat`.
  - Live `firewalld` state check (ensures `http` and `https` services are allowed through the host firewall).
  - Practical Windows DNS advice for resolving route hostnames in `C:\Windows\System32\drivers\etc\hosts`.
- **🌐 Open in Default Browser**: Directly launch exposed route URLs in Windows browser.
- **✏️ Interactive YAML Editor**: Inspect and edit route configurations live.

### 6. 🐳 Docker & Podman Containers
- View all running and stopped containers (`podman ps -a` / `docker ps -a` / `crictl ps -a`).
- Container lifecycle controls: **Start**, **Stop**, **Restart**, **Remove**, and **Logs**.

### 7. 🖼️ Container Images
- Repository, Tag, Short ID, Virtual Size, and Created date.
- **⬇️ Pull Image**: Interactive dialog to pull images from Quay.io, Docker Hub, or Red Hat registries.
- **🗑️ Delete Image**: Remove images from the host engine.

### 8. 📁 Node Remote File Explorer
- Browse remote Linux node filesystems (e.g. `/var/log`, `/etc/microshift`, `/etc/kubernetes`) over SFTP or shell fallback.
- **File Viewer**: In-app viewer with copy and download capabilities.

### 9. ⚙️ Connection Profiles & Settings
- Save and switch between multiple MicroShift / OpenShift cluster nodes.
- Supports IP/Host, Port, Username, Password, Sudo Password, SSH Private Key path, and custom KUBECONFIG overrides.
- Configurable auto-refresh interval (Manual, 10s, 30s, 60s).
